# ImGui Window App Todo

Небольшой desktop-проект на C++ с использованием Dear ImGui, GLFW и OpenGL.  
Сейчас приложение представляет собой заготовку окна с кастомной рамкой/титлбаром и базовой интеграцией ImGui.

> ⚠️ Проект пока не завершён. Часть функционала находится в разработке и будет дорабатываться позже.

## Стек

- C++17
- CMake
- Dear ImGui
- GLFW
- OpenGL / GLAD

## Что уже есть

- создание прозрачного окна без стандартной рамки;
- инициализация ImGui через GLFW + OpenGL;
- базовый класс для работы с ImGui;
- кастомный titlebar;
- заготовка кнопок управления окном;
- базовая структура проекта под дальнейшую разработку.

## Сборка

Проект ориентирован на сборку через CMake. Удобнее всего открыть его в CLion или другой IDE с поддержкой CMake.

Пример сборки из консоли:

```bash
git clone <repo-url>
cd Imgui_Window_App_Todo
mkdir build
cd build
cmake ..
cmake --build .
```

После сборки исполняемый файл появится в директории сборки.
